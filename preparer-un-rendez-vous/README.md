# Préparer un rendez-vous

> Le dossier de la personne, en une page.

## Français

**Ce que fait ce skill.** Prépare une fiche de rendez-vous sur une personne et son entreprise : parcours, actualité, sujets d'intérêt, historique d'échanges, questions à poser et pistes d'ouverture. À utiliser avant un appel, un café ou un entretien.

**Comment l'utiliser.** Collez cette phrase dans Claude, ChatGPT ou Cursor :


Pour qu'il agisse sur votre LinkedIn, branchez Agraff : https://getagraff.com/connexion
