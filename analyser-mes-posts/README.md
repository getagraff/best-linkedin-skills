# Analyser les statistiques de mes posts

> Ce qui marche, ce qui ne marche pas, et quoi faire.

**Ce que fait ce skill.** Lit les statistiques des publications récentes de l'utilisateur (impressions, réactions, commentaires), repère les formats et sujets qui fonctionnent et recommande des actions concrètes pour les prochains posts. À utiliser chaque semaine ou chaque mois.

**Comment l'utiliser.** Collez cette phrase dans Claude, ChatGPT ou Cursor :

