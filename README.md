# agraff-skills

Skills publics d'[Agraff](https://getagraff.com) : des instructions prêtes à l'emploi pour piloter votre LinkedIn depuis votre IA (Claude, ChatGPT, Cursor).
Public skills for [Agraff](https://getagraff.com): ready-to-use instructions to run your LinkedIn from your AI (Claude, ChatGPT, Cursor).

---

## Français

### Comment ça marche
1. Choisissez un skill ci-dessous : chaque dossier contient un fichier `SKILL.md` (les instructions) et un `README.md`.
2. Collez dans votre IA la phrase du `README.md` du skill, par exemple :
   ```
   Installe ce skill : lis https://raw.githubusercontent.com/getagraff/agraff-skills/main/boite-de-reception/SKILL.md et suis les instructions
   ```
3. Rien à télécharger ni à installer : l'IA lit le fichier et suit les instructions.

### Installer
- **Claude Code** : `/plugin marketplace add getagraff/agraff-skills`, puis `/plugin install agraff@agraff-skills`.
- **Cursor** : ajoutez le plugin avec « From GitHub Repository » et l'adresse `getagraff/agraff-skills`.
- **ChatGPT** : un admin Business, Enterprise ou Edu importe la marketplace.
- **Autre IA** : collez l'adresse `https://github.com/getagraff/agraff-skills` et demandez-lui de lire les skills.

### Pour qu'il agisse sur votre LinkedIn
Les skills ne font que dire à votre IA comment s'y prendre. Pour qu'ils agissent sur votre LinkedIn, branchez Agraff à votre IA : https://getagraff.com/connexion

## English

### How it works
1. Pick a skill below: each folder holds a `SKILL.md` file (the instructions) and a `README.md`.
2. Paste the sentence from the skill's `README.md` into your AI, for example:
   ```
   Install this skill: read https://raw.githubusercontent.com/getagraff/agraff-skills/main/inbox-triage/SKILL.md and follow the instructions
   ```
3. Nothing to download or install: the AI reads the file and follows the instructions.

### Install
- **Claude Code**: `/plugin marketplace add getagraff/agraff-skills`, then `/plugin install agraff@agraff-skills`.
- **Cursor**: add the plugin with "From GitHub Repository" and the address `getagraff/agraff-skills`.
- **ChatGPT**: a Business, Enterprise or Edu admin imports the marketplace.
- **Any other AI**: paste the address `https://github.com/getagraff/agraff-skills` and ask it to read the skills.

### For it to act on your LinkedIn
Skills only tell your AI how to proceed. For them to act on your LinkedIn, connect Agraff to your AI: https://getagraff.com/connexion
