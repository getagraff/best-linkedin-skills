# Trier et accepter les invitations reçues

> Accepter les bonnes, décliner les autres, répondre aux nouvelles.

## Français

**Ce que fait ce skill.** Passe en revue les invitations de connexion reçues, les classe (à accepter, à décliner, à examiner) selon la cible de l'utilisateur, répond aux acceptations par un message d'accueil. À utiliser pour vider la file d'invitations sans y passer l'heure.

**Comment l'utiliser.** Collez cette phrase dans Claude, ChatGPT ou Cursor :

```
Installe ce skill : lis https://raw.githubusercontent.com/RubenTaieb2/agraff-skills/main/invitations-recues/SKILL.md et suis les instructions
```

Rien à télécharger : votre IA lit le fichier [`SKILL.md`](https://github.com/RubenTaieb2/agraff-skills/blob/main/invitations-recues/SKILL.md) et suit les instructions.

Pour qu'il agisse sur votre LinkedIn, branchez Agraff : https://getagraff.com/connexion

## English

**Sort and accept received invitations.** Accept the good ones, decline the rest, welcome the new ones.

**What it does.** Goes through received connection invitations, sorts them (accept, decline, review) against the user's target, and answers acceptances with a welcome message. Use to empty the invitation queue without spending an hour on it.

**How to use it.** Paste this sentence into Claude, ChatGPT or Cursor:

