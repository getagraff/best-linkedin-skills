# Rapport hebdomadaire de prospection

> L'état de votre activité LinkedIn en une page.

**Ce que fait ce skill.** Fait le point sur l'activité de la semaine : relations, invitations envoyées et reçues, conversations, publications, crédits InMail, et propose les priorités de la semaine suivante. À utiliser chaque lundi ou chaque vendredi.

**Comment l'utiliser.** Collez cette phrase dans Claude, ChatGPT ou Cursor :

```

Pour qu'il agisse sur votre LinkedIn, branchez Agraff : https://getagraff.com/connexion

**How to use it.** Paste this sentence into Claude, ChatGPT or Cursor:

```
